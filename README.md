# Power BI Dashboard - Анализ продаж и логистики онлайн-магазина 

Этот проект демонстрирует полный цикл аналитики: от очистки «сырых» данных на Python до построения интерактивного дашборда в Power BI для принятия управленческих решений.

## Стек технологий
* **Python (Pandas):** Очистка данных, обработка дат, создание новых метрик (`Profit Margin`, `Shipping Duration`).
* **Power BI:** Создание интерактивной отчетности (KPI, динамика, география).

##  Основные задачи и результаты
1. **Подготовка данных:** Исправила ошибки кодировки, привела даты к верному формату и рассчитала ключевые метрики эффективности.
2. **Анализ показателей:**
   - Рассчитала **Average Order Value (AOV)** и **Profit Margin** по категориям.
   - Выявила зависимость между сроком доставки и объемом заказов.
   - Определила топовые города по объему выручки для оптимизации логистической сети.
3. **Визуализация (Power BI):** 
   - Построила дашборд с основными KPI компании.
   - Реализовала возможность интерактивной фильтрации по годам и категориям товаров.

##  Бизнес-выводы
* **Категории:** Основной объем заказов приходится на категорию *Office Supplies*, однако *Technology* показывает высокую маржинальность.
* **Логистика:** Средний срок доставки (41 день) значительно выше ожиданий, что требует пересмотра работы логистических центров в ряде регионов.
* **География:** *New York City* является ключевым рынком, обеспечивающим стабильный поток заказов.

##  Структура репозитория
* `pre.ipynb` — Jupyter Notebook с процессом очистки данных (Data Prep).
* `super_store.pdf` — PDF-версия дашборда Power BI.
